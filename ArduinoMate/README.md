## Installation and Setup

### Requirements

- Python 3.10 or newer (3.13 recommended)
- pip

### 1. Navigate to the project

```bash
cd ArduinoMate
```

### 2. Create and activate a virtual environment

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

## API Endpoint Documentation

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Health check + record count |
| GET | `/records` | All 20 records |
| GET | `/records?limit=N` | First N records |
| GET | `/records/{id}` | Record by ID (404 if missing) |
| GET | `/search?q=query` | TF-IDF smart search |
| GET | `/search?q=query&limit=N` | Smart search with result limit |
| POST | `/questions` | Submit a user question |

### Swagger UI (interactive docs)
```
http://127.0.0.1:8000/docs
```

### ReDoc UI
```
http://127.0.0.1:8000/redoc
```

## Example API Requests and Responses

### GET /health
```bash
curl http://127.0.0.1:8000/health
```
```json
{
  "status": "healthy",
  "service": "ArduinoMate API",
  "version": "1.0.0",
  "total_records": 20,
  "timestamp": "2026-11-12T10:00:00+00:00"
}
```

### GET /records/7
```bash
curl http://127.0.0.1:8000/records/7
```
```json
{
  "function_name": "digitalRead",
  "category": "Digital I/O",
  "syntax": "digitalRead(pin)",
  "returns": "HIGH or LOW",
  "common_gotcha": "If the pin isn't connected to anything, digitalRead() can return either HIGH or LOW randomly.",
  "source_url": "https://docs.arduino.cc/language-reference/en/functions/digital-io/digitalread/",
  "id": 7,
  "description": "Reads the value from a specified digital pin, either HIGH or LOW."
}
```

### GET /search?q=analog pin
```bash
curl "http://127.0.0.1:8000/search?q=analog+pin&limit=3"
```
```json
{
  "query": "analog pin",
  "total_matches": 3,
  "results": [
    {
      "function_name": "analogRead",
      "category": "Analog I/O",
      "similarity_score": 0.7912
    }
  ]
}
```

### GET /records?limit=0 (error handling)
```bash
curl "http://127.0.0.1:8000/records?limit=0"
```
```json
{ "detail": "Limit must be a positive integer greater than 0." }
```

### GET /records/9999 (404)
```bash
curl http://127.0.0.1:8000/records/9999
```
```json
{ "detail": "Record with ID 9999 not found." }
```

### POST /questions
```bash
curl -X POST http://127.0.0.1:8000/questions \
  -H "Content-Type: application/json" \
  -d '{"user_name":"Parth","question":"What does pinMode do in Arduino?","category":"Digital I/O"}'
```
```json
{
  "message": "Question submitted successfully.",
  "question_id": 1,
  "data": {
    "id": 1,
    "user_name": "Parth",
    "question": "What does pinMode do in Arduino?",
    "category": "Digital I/O",
    "created_at": "2026-11-12T10:05:00+00:00"
  }
}
```
